# NIFTY 50 Event Study: Post-Shock Market Recovery

A reproducible quantitative research pipeline for studying how the **NIFTY 50 Index** behaves after significant one-day declines.

The current research question is:

> **After a significant one-day decline in NIFTY 50, do subsequent 1-, 3-, 5-, or 10-trading-day returns differ from normal market returns?**

The project uses historical NIFTY 50 data from **2007 onward** from the selected Kaggle dataset and follows an event-study methodology with a frozen development/OOS split.

---

## 1. Research Objective

The project investigates whether a significant one-day market decline is followed by an abnormal recovery pattern.

### Primary event definition

An event occurs when:

```text
Daily close-to-close return <= -3%
```

where:

```text
event_return[t] = Close[t] / Close[t-1] - 1
```

For each event, subsequent returns are measured using:

```text
Entry  = next trading day's Open
Exit   = Close after h trading observations
```

with:

```text
h ∈ {1, 3, 5, 10}
```

Therefore:

```text
ForwardReturn(h)
    = Close[t+h] / Open[t+1] - 1
```

# 6. Phase 3 — Forward Return Engine

### Status

**Completed**

For every qualifying event, forward returns are calculated at:

```text
1 trading day
3 trading days
5 trading days
10 trading days
```

The trade convention is:

```text
Event day       = t
Entry           = Open[t+1]
Exit            = Close[t+h]
```

Therefore:

$$
R_h =
\frac{Close_{t+h}}
{Open_{t+1}}
-1
$$

# 12. Current Research Interpretation

The current evidence can be summarized as follows:

> In the primary −3% event sample, post-event mean returns are above the non-event baseline at the 1-, 3-, and 5-trading-day horizons, with the largest observed point estimate at five trading days. However, the 95% bootstrap confidence intervals for the event-minus-baseline differences include zero at every tested horizon. The OOS period shows smaller positive differences at the 1-, 3-, and 5-day horizons, while the 10-day difference becomes negative. Given the small OOS event count, these estimates remain imprecise.

The analysis therefore **does not yet establish a statistically reliable recovery effect**.

The current results should be treated as preliminary empirical findings.

# 16. Limitations Identified So Far

The current implementation has several limitations that must be addressed before final conclusions.

### 16.1 Small event sample

Only:

```text
53 total events
15 OOS events
```

are currently available.

This produces relatively wide uncertainty intervals.

### 16.2 Baseline contamination

The current baseline removes event dates but does not yet explicitly remove the complete post-event recovery window.

A stricter baseline specification is required.

### 16.3 Temporal dependence

Financial returns are not necessarily IID.

Bootstrap results based on independently resampling individual observations therefore represent an initial inference specification rather than the final statistical methodology.

### 16.4 Multiple horizons

Four horizons are being evaluated:

```text
1D
3D
5D
10D
```

Observed differences should not be interpreted independently without considering multiple comparisons.

### 16.5 Threshold selection

Only the −3% threshold has currently been evaluated.

The robustness of the result across alternative thresholds has not yet been tested.

# 19. Research Principle

The project follows a strict separation between:

```text
Discovery
    ↓
Development
    ↓
Validation
    ↓
Out-of-Sample Evaluation
    ↓
Robustness
    ↓
Economic Testing
```

No final trading conclusion should be drawn from the current descriptive results alone.

The objective is not merely to identify a historical pattern, but to determine whether the pattern is:

1. statistically distinguishable from noise,
2. robust to reasonable methodological choices,
3. persistent out-of-sample,
4. economically meaningful after costs, and
5. reproducible without look-ahead bias.
